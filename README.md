## 💻 Tech Stack & Architecture

- **HTML5**: Semantic, accessible markup (WCAG 2.1 AA compliant)
- **CSS3**: Modern CSS custom properties, asymmetric grid layouts, fluid clamp typography, backdrop filters, 3D paper tilts
- **Vanilla JavaScript (ES6+)**: Zero dependencies, no frameworks or build steps required
- **Form Submission**: Connected to `ahirzia@gmail.com` with automated CC routing to dedicated journal desks and native mailto fallback

## 🚀 Running Locally

No build tools or package managers required. Simply serve the directory with any static server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js npx
npx serve .
```

Open `http://localhost:8080` in your web browser.
